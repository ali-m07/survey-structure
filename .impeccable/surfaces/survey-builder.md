# Survey builder

Mode: Operate. Preserve the Porsnama cream/plum identity.

The primary task is composing a survey. Twelve supported question types must be visible immediately; the active question has a focused editor, and pages/questions remain navigable in an outline. Survey-level settings are secondary and collapsed by default.

Goal-based AI generation is a separate collapsible entry. Generated proposals are reviewed before explicit application; existing survey questions remain intact. Manual creation remains available regardless of model connectivity. Persian, English and French use the same hierarchy, with RTL/LTR and mobile structural reflow.
The selected question also shows real answer controls, including the NPS 0–10 scale. Conditions use a visible source/operator/value editor and explain why the first question cannot depend on an earlier answer. Optional authored HTML supports scoped text formatting with a plain wording fallback. Plain lists and typed JSON support bulk question import, with an item count and review before atomic application.On mobile, the outline starts collapsed and summarizes the active question and total count; its open list is bounded and scrollable. Answer-based jump rows have their own initially closed disclosure when later destinations exist. Without a later question, a localized helper replaces the destination rows.
